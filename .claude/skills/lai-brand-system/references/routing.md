# Enrutamiento por tipo de pieza

Las rutas se resuelven desde la raíz de `LONGEVITY_ACADEMY_INSTITUTE/`.

## Identidad, logo o portada

- Abrir `00_fuente_original/LAI-brand-suite/Manual de Marca LAI.dc.html` mediante servidor local.
- Usar `marca/logos/v2/` y `marca/degradados/`.
- Consultar `Kit de logotipo LAI.dc.html` para variantes y fondos.

## Web o interfaz

- Cargar `styles.css` y los tokens de `tokens/`.
- Consultar `components/core/*.prompt.md` y el componente correspondiente.
- Tratar `Pantallas LAI.dc.html` como muestra, no como aplicación lista para producción.
- Validar teclado, foco, contraste, reducción de movimiento y comportamiento responsive.

## Redes, infografía o presentación

- Usar cuerpo mínimo de 24 px y máximo tres niveles.
- Elegir degradados “dos/tres colores” o mallas según el manual.
- Usar iconos de `marca/iconos/` y comprobar formato/dimensiones del canal.

## Documento, libro o artículo

- Consultar las secciones de texto científico de `MARCA.md` y `readme.md`.
- Usar Arimo 10.5 pt / 1.35, dos columnas cuando aplique y pies de figura de tres capas.
- No convertir el régimen editorial científico en una regla para piezas de comunicación.

## Ilustración médica

- Leer completo `00_fuente_original/LAI-brand-suite/marca/ILUSTRACION-MEDICA.md`.
- Usar el prompt como fuente especializada del artefacto, respetando los límites de `AGENTS.md`.
- Mantener paleta biológica dentro de la figura; aplicar marca solo en el montaje posterior.

## Oferta o convocatoria

- Consultar `02_catalogos/OFERTA_Y_DATOS_EXTRAIDOS.md`.
- Confirmar vigencia de precio, fecha, modalidad, aval, certificación y CTA antes de publicar.
