# LAI Brand System

Sistema de diseño de marca del **Longevity Academic Institute (LAI)**.
Dra. Carolina Rodríguez Morales · Medellín, Colombia.

Repositorio hermano de `lci-clinical-scribe` (app clínica). Aquí vive solo marca:
logos, credenciales, fotografía, tokens, tipografías, componentes y guidelines.

## Estructura

```
brand/
  logos/
    lai/            Logos oficiales LAI (versión definitiva: V2)
    aliados/        Longevity Clinical Institute · Longevity Research Institute
  credenciales/
    kharrazian-institute/   Logo y emblema del Kharrazian Institute
    afmc/                   Sello AFMC (Advanced Functional Medicine Clinician)
    cfmc/                   Sello CFMC (Certified Functional Medicine Clinician)
  fotografia/
    dra-carolina/   Retratos oficiales
tokens/             Paleta, tipografía, gradientes, efectos (CSS, fuente Drive)
fonts/              Tipografías embebidas (Lato, Arimo)
components/         Componentes HTML autocontenidos
templates/decks/    Opciones de diseño del deck de formación académica
guidelines/         Brandbook LAI
```

## Convenciones de archivos

- PNG con fondo transparente, tamaño original.
- Sufijo `-trim`: mismo asset con los márgenes transparentes recortados (4 % de aire).
- Sufijo de color: `-navy` (tinta navy sobre fondo claro), `-blanco` (tinta blanca para fondos oscuros),
  `-fondo-navy` (arte sobre placa navy).
- Nombres en minúsculas, sin espacios, con guiones.
