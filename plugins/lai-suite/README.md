# lai-suite — Longevity Academic Institute

Suite de marca y producción académica de **Longevity Academic Institute®**.
Marca **independiente** de `lci-suite` (la clínica): otras tipografías, otra paleta, otro escudo.

| | LAI (esta suite) | LCI (`lci-suite`) |
|---|---|---|
| Tipografías | Lato + Helvetica (Arimo) | Poppins + Mencken Std |
| Color base | Navy `#1B1464` · azul `#3640D7` | Navy `#2A3649` |
| Acento | Cian `#00F6E3` · teal `#4AF1D2` | Gold `#D2B58A` |

## Skills

| Skill | Para qué |
|---|---|
| `lai-design-system` | Motor de marca. Paleta, fuentes embebidas, kit de logos, patrón, componentes, tratamiento de imagen. Lo invocan los demás. |
| `lai-infografia-modulo` | Infografías de módulo y one-pagers clínicos, con el formato maestro. |
| `lai-piezas-graficas` | Stories, posts, carruseles, flyers, banners, agendas, escarapelas, firma de correo. |
| `lai-material-curso` | Compendios, cuadernillos, portadas, syllabus, handouts, certificados, membrete, cartas, decks. |
| `lai-marketing` | Voz de marca, convocatorias, secuencias de correo, landing, comunicados. |
| `lai-evidencia` | PubMed, niveles de evidencia, citas con DOI/PMID, fichas de péptido, checklist de verificación. |

## Material de marca embebido

- **Logos v2** (alfa, del Manual de Marca LAI v2): horizontal navy y blanco, vertical navy y blanco, escudo v3 con llama, wordmark navy y blanco, firma de la Dra. Carolina.
- **Elementos**: llama maciza, llama de contorno, escudo silueta, escudo de línea (SVG + PNG navy y blanco).
- **27 iconos** de línea + aval Florida Global University (SVG `currentColor` + PNG 512 azul y blanco).
- **14 degradados oficiales**, recuadro biselado y fichas de infografía (Manual v2).
- **Fuentes**: Lato (thin→black, con cursivas) + Arimo (sustituto libre y métricamente compatible de Helvetica).
- **Retratos** de la fundadora (incluye recorte con fondo transparente).
- **Avales**: Kharrazian Institute (blanco, color, laurel), sellos AFMC y CFMC.
- **Fondos de slide** 1920×1080 aprobados y plantilla `portada_docente`.
- **28 piezas maestras** de referencia: infografías, portadas, certificado, escarapelas, stories, membrete, mockups.
- **Documentos fuente**: brochure corporativo, propuesta de plataforma, comunicado institucional, 10 infografías de módulo en PDF.

Nada hay que volver a subir.

## Reglas transversales

1. El contenido clínico de la doctora se reproduce **VERBATIM**. Nunca se resume, reinterpreta ni inventa.
2. Toda afirmación científica pasa por `lai-evidencia` con DOI o PMID real.
3. Toda pieza se **renderiza y se revisa** antes de entregarse.
4. Cifras institucionales (módulos, horas, avales) se confirman con la doctora antes de publicar.
5. Nunca mezclar la identidad de LAI con la de LCI.
